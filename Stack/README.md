# Stack

## 정의

마지막에 넣은 데이터가 가장 먼저 나오는 구조(LIFO, Last In First Out)

## 특징

데이터를 항상 top에서만 넣고 빼기 때문에 모든 연산이 O(1).

중간에 있는 원소에 바로 접근할 수는 없음.

js의 배열을 사용해 구현할 수도 있고 연결리스트를 사용해 만들 수도 있음

## 주요연산

- 맨 위에 원소 추가
- 맨 위 원소를 꺼내서 반환
- 맨 위 원소 확인
- 비어있는 지 확인
- 원소개수 확인

## 활용사례

- 함수 호출 스택(js 엔진)
- 되돌리기 작업(undo)
- DFS, 후위 표기식 계산 등

> js 의 Array 는 stack의 연산(pop)을 지원하고 있다.
