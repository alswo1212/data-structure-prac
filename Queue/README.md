# Queue

## 정의

데이터를 삽인한 순서대로 삭제하는 선형 자료구조.

FIFO(First In, First Out) 원칙을 따른다.

> 편의점 알바할 때 많이 듣던 그 선입선출이다.

## 주요연산

- Enqueue: 큐의 뒤에 데이터를 삽입
- Dequeue: 큐의 앞에서 데이터를 꺼내 반환
- Peek / Front: 맨 앞의 데이터를 반환(삭제X)
- isEmpty: 큐가 비어있는지 확인

## 큐의 특징

1. FIFO(선입선출) 구조
2. 삽입은 뒤에서, 삭제는 앞에서
3. 삽입과 삭제 전부 O(1) 소요
