# Linked List

## 정의

데이터를 저장하는 노드(Node)들이 포인터를 통해 서로 연결된 자료구조

## 특징

배열(Array)은 데이터가 메모리에 연속저긍로 저장되지만,<br>
연결 리스트는 데이터가 메모리의 서로 다른 위치에 저장되고 포인터를 통해 연결된다.

각 노드는 실제 저장할 값(data)과 와 다음 노드의 메모리 주소(next)를 가지고 있음.

- 불연속적인 메모리 공간을 사용
- 데이터에 순차적으로 접근
- 삽입과 삭제 시 포인터 변경으로 끝
- 동적으로 크기 변경가능
- 추가적으로 포인터를 저장할 공간이 필요

### 변형?

- `Doubly Linked List`: 각 노드가 전,후 노드의 주소를 모두 저장. 양방향 이동 가능
- `Cicular Linked List`: 마지막 노드가 첫 번째 노드를 가리켜서 원형으로 연결

## 주요연산

- 노드 추가
- 노드 제거
- 노드 탐색
