# Heap

## 정의

최댓값 혹은 최솟값을 빠르게 찾기위해 고안된 완전 이진 트리 기반 자료구조

## 특징

- 완전 이진 트리형태이며 마지막 레벨을 제외하고 모든 레벨이 꽉 차있음
- 힙 속성(Heap Property) - 부모 노드와 자식 노드 간에 대소 관계가 성림
- 형제 간 순서 없음
- 중복 허용

## 주요연산

- 삽입 - 새 노드를 힙의 가장 끝에 삽입 후, 부모 노드와 비교해 위치를 조정해 힙 구조를 유지
- 삭제 및 반환 - 루트 노드를 트리에서 제거하고 반환. 남은 트리는 재조정해서 힙 구조를 유지
- 루트 노드 확인 - 루트에 있는 최댓값 혹은 최솟값 확인.

## 활용사례

- 우선순위가 있는 스케줄러, 대기열
- 다익스트라 알고리즘(최단 거리 찾는 알고리즘)
