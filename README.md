# data-structure-prac

### 만들게 된 이유

ai 사용해서 개발하다가 오랜만에 코테를 풀어보니 <br>
머리가 안돌아가고 손도 안 움직이는걸 확 느낌.

그리고 어떤 문제 풀다가 도저히 풀이가 생각이 안나고 <br>
뭔가 Linked List를 잘 써보던가 B+Tree 를 만들면 풀 수 있을 것 같다는 생각만 들었음.

그러면 자료구조 구현하는거 연습해보자. 하는김에 다른것도 해보자. 해서 시작함.

### 목적

js 로 자료구조를 메모장에 손코딩 가능하게 만들기

### 사용 언어

`js`

왜? 지금 fe로 일하고 있으니까.

### 공부 방법

1. 매주 하나의 자료구조를 공부
2. 자료구조의 정의와 사용예시를 정리
3. AI 를 사용해 코드 구현(내가 바로 짜지는 못할거 같음)
4. 코드를 이해하고 외우기
5. 메모장에 혼자 작성할 때까지 4 반복
